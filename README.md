## 📖 About

🔹 **Terraria — Max Stack Plus** is a powerful tool built to help you dramatically increase item stack sizes in Terraria to reduce inventory clutter and chest hoarding. Stack up to 9999 of any stackable item, reducing the number of chests needed to organize your base.

🔸 Whether you're a seasoned professional or just getting started, **Terraria — Max Stack Plus** delivers a clean, intuitive experience packed with everything you need — right out of the box. | Feature | Description |
